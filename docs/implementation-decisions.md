# 구현 해석 — paper-interpretation-v1

사용자는 Phase 1 검토 후 Phase 2–6 구현을 승인했습니다. 아래 선택은 **원문에 없는 실행 의미를 정한 연구용 정책**입니다.
원문의 수치를 추가로 발견했다고 주장하지 않습니다. 사실·인용은 [원본 전략](original-strategy-spec.md)을 기준으로 합니다.

## 원문 미정의 항목의 실행 의미

| 항목 | 이 구현의 선택 |
| --- | --- |
| Kelly | 표준 `max(0, (b*p-(1-p))/b)`. 확률·수익 배수는 VET의 추정치이며 관측 사실과 구별. BOOK은 outcome의 p와 `(1-ask)/ask` 사용 |
| 6% | 주문 **명목 금액** 상한. 목표 비중이나 Kelly 대체값이 아님. 수수료는 별도 현금 예약 |
| 최소 주문 | 실제 신규 체결 명목 금액 50달러 이상. 수량 내림 때문에 50 미만이면 거절. 위험 청산에는 최소 진입 금액을 강제하지 않음 |
| PASS_PARTIAL | 진입 차단. 누락된 집중도·보유자·호가 자료를 LLM 승인으로 대체하지 않음 |
| 추가 매수 | 최초 진입가의 1.5배 이상인 관측 고점 이후, 진입가보다 높고 고점보다 낮은 가격에서 1회만 허용. 현재 6%·현금·유동성·모든 VET 조건 재검사 |
| 두 매도 우위 구간 | 원천에서 제공된 겹치지 않는 구간만 사용. 누적 h1/h6 값을 서로 독립된 구간으로 간주하지 않음. 구간이 없으면 VET 차단 |
| BOOK 차이 | 선택 outcome의 `추정 확률 - ask > 0.08` 확률 포인트. 정확히 0.08은 진입하지 않음 |
| 시장 매칭 | 제목·resolution rules·마감 시각의 정확한 일치. LLM이나 fuzzy match로 일치를 주장하지 않음 |
| 체결 | 검증된 시각·출처·자산·방향의 실제 호가 깊이에 대한 모의 IOC. 2% 이내 레벨만 순서대로 소진. 잔량은 취소 |
| 부분 체결 비용 | 한 모의 주문의 합산 체결 금액에 `max(0.0045*N,0.95)`를 1회 적용. 재요청이 새 주문이면 비용도 새로 발생 |
| 수량 정밀도 | 1e-9 단위 내림, 금액은 Decimal. 거래소별 실제 lot/tick 제약을 구현했다고 주장하지 않음 |
| 수수료 바닥 | 신규 진입에서 유효 비용이 2%를 넘거나 실제 체결 명목 금액이 50 미만이면 FEE_FLOOR. 20달러 예시는 최소 진입 단계에서 먼저 거절 |
| 일중 10% 알림 | 서울 날짜의 **첫 유효 평가 자산**을 기준으로 절대 변화가 10%를 초과하면 하루 한 번 내부 감사/대시보드에 기록. 외부 메시지를 보내지 않음 |
| 응답 감독 | 역할별 연속 2회 실패에 동일 설정의 stateless client 재생성 요청. 1시간 내 두 번째 재생성 조건이면 신규 진입 정지. 강제 청산하지 않음 |

## 시간과 자료

- 시간은 timezone-aware UTC로 저장합니다. 스케줄은 SCAN 15분, RISK 5분, CHIEF 23:00 Asia/Seoul입니다.
- 수집 시각 `fetched_at`과 공급자 관측 시각 `observed_at`을 구별합니다. 기본 시장 300초·실행 호가 60초 이내를 검사합니다.
- DexScreener 응답의 원천 관측 시각, 보유자 이력, whale 매도 상태, 실제 실행 깊이는 알려지지 않습니다. 이 필드는 null로 남고 자동 진입을 막습니다.
- Solana largest accounts / supply는 **최대 토큰 계정 비율**입니다. 실소유 지갑 집중도로 이름을 바꾸지 않습니다.
- legacy SPL mint/freeze authority 검사는 제한된 계약 점검입니다. 포괄적인 스마트 계약 감사가 아닙니다. 전체 보유자 스캔은 기본 비활성입니다.
- 온체인 Adapter와 공개 호가 Adapter는 구현했지만, 보유자·두 구간·whale 매도의 신뢰할 수 있는 연속 자료를 채우는 외부 indexer는 구성되지 않았습니다.
- 기존 가격이나 중간가를 체결 증거로 사용하지 않습니다. 가격 없는 RISK는 `close_requested_unpriced`로 남으며 현금이나 수량을 바꾸지 않습니다.
- RISK의 `20*h6 < h24`는 `h6/(h24/4) < 0.20`과 동일한 Decimal 비교입니다. +50% 시총은 HOLD, +60%는 flag이며 자동 익절이 아닙니다.

## 상태·원장·권한

- 주문·현금·보유 수량·체결·수수료·감사 체인은 한 DB 트랜잭션에서 반영합니다. PostgreSQL 계정 행 잠금으로 동시 요청을 직렬화합니다.
- SQLite는 개발·독립 데모용입니다. 다중 서비스에는 PostgreSQL Compose를 사용하세요.
- 주문 ID와 사이클 request ID는 영속적인 멱등 키입니다. 다른 주문 의도로 같은 ID를 재사용하면 거절합니다. 소비한 호가 깊이는 계정별로 기록합니다.
- 공용 설정 버전을 DB에 저장합니다. 변경 전 프로세스의 새 LLM 호출과 신규 체결은 차단합니다. RISK 청산은 계속 가능합니다.
- Kill Switch는 신규 진입을 중지합니다. 자동·무가격 청산을 발생시키지 않습니다. 변경 사유는 필수이며 API 쓰기에는 로컬 관리 토큰이 필요합니다.
- fixture 계정과 실제 공개 자료 계정은 섞지 않습니다. 합성 자료는 실제 모델 검증·수익성 근거가 아닙니다.
- 해시 체인은 앱의 감사 기록 변경을 탐지합니다. DB 소유자에 의한 전체 원장 재작성까지 막는 외부 공증 체계는 아닙니다.
- 초기 schema는 SQLAlchemy metadata로 생성합니다. 향후 schema 변경에는 명시적인 migration이 필요합니다. 기존 장부 삭제·초기화 명령은 제공하지 않습니다.

## LLM 경계

사용자 선택에 따라 전역 Provider를 loopback-only `llama_cpp`로 설정했습니다. 가중치 URL·SHA-256과 모델 ID는 환경변수에서 선택합니다.
고정 CPU runtime·검증된 GGUF 하나를 사용하고, 도구·MCP·agent 모드는 비활성화합니다. 네 역할의 실제 로컬 schema probe를 통과했습니다.
로컬 토큰은 `local_inference_usage`로 보존하며 외부 API 요금으로 환산하지 않습니다.
모델 출력 schema의 Decimal 필드는 JSON number만 허용합니다. 제약 없는 문자열 분기는 constrained decoder가 수치 범위를 우회하게 합니다.
llama.cpp grammar는 number의 범위를 강제하지 않으므로 VET 손익비는 0 이상을 받고, 0은 추정 없음으로 보아 SIZE가 0을 계산합니다.

단일 HTTP Adapter 구현은 네이티브 Provider의 JSON schema API를 사용합니다. SDK/LiteLLM 대신 httpx를 채택해 의존성을 줄였습니다.
각 Provider 계약은 HTTP mock으로 검사했으며 **유료 실제 모델의 호환성을 검증한 것은 아닙니다**.
구조화 출력·인증·모델 ID가 맞지 않으면 같은 모델 내 제한된 재시도 후 중지합니다. 도구 호출 API를 제공하지 않습니다.
Codex CLI는 기존 로그인과 ephemeral/read-only 실행, 사용자 config 무시, MCP·shell·patch·multi-agent·web 기능 차단 설정을 사용합니다.
CLI 이벤트에 도구 실행이 나타나면 결과를 거절합니다. 모델의 텍스트 지시만으로 주문을 만들지 않습니다.
Claude·Gemini·Qwen·OpenCode·Copilot·Goose·Ollama CLI도 전역 설정 하나로 선택할 수 있습니다.
native 도구 제한과 종료·모델·schema 검사를 적용하며, 기타 CLI는 신뢰하는 inference 전용 JSON 브리지로 연결합니다.
CLI별 설치 확인과 실제 인증·추론 성공은 구별합니다. 모든 CLI/버전에 대한 OS sandbox나 호환성을 보장하지 않습니다.
상세 계약과 검증 범위는 [CLI 호환 가이드](cli-providers.md)에 기록합니다.

BOOK 입력에는 시장 가격이 없습니다. 근거 내용·원천·시간이 없으면 중지하며, 확률 결과를 DB에 저장한 **뒤** 가격 로더를 호출합니다.
CHIEF 출력은 보고용입니다. SIZE/FILLS/RISK의 함수나 승인을 바꾸는 명령으로 해석하지 않습니다.

## 자동 작업·예측 정산

자동 수집·모델 점검·SCAN·BOOK·RISK·보고를 별도 작업과 lease로 실행합니다. 모델 점검과 수집이 서로를 기다리지 않습니다.
자동 실행은 필수 자료를 생략하는 승인이 아닙니다. 원본 밈코인 게이트는 유지하며, 외부 관측 feed도 Dex에서 발견한 같은 자산·pool에만 결합합니다.
BOOK 질문·최근 파생 근거는 WM 발견 ID와 공식 venue metadata로 조립합니다. 확률을 먼저 저장하고 가격을 별도로 읽습니다.
확정된 이진 결과만 계약당 0/1 USD로 모의 정산합니다. redemption fee는 0으로 해석하며 이미 차감한 진입 수수료는 유지합니다.
void·분쟁·비이진·불명확 결과는 정산하지 않습니다. 이는 원문이 정의하지 않은 예측 계약의 실행 의미를 정한 연구용 정책입니다.
정산은 원장·현금·수량·성과 에피소드·증거 snapshot·감사 체인을 원자적으로 반영하며 같은 포지션에 중복 입금하지 않습니다.

## 성과와 비교

승률·Profit Factor는 포지션을 열어 완전히 닫을 때까지의 거래 단위로 계산합니다. 부분 매도 건수를 승리 횟수로 부풀리지 않습니다.
열린 포지션의 유효 평가가 없으면 equity/미실현 손익/수익률을 N/A로 표시합니다.
평가는 snapshot price 기준이며 호가 잔량·추가 비용을 반영한 즉시 청산 순금액을 보장하지 않습니다.
최대 낙폭은 수집한 자산 표본에 대한 값이고, 가격 없는 구간은 제외한 개수를 공개합니다.
비용을 모르면 API 비용을 0으로 두지 않습니다. Codex 구독 토큰과 과금 방식이 불명확한 native CLI 토큰은 API 청구 금액으로 환산하지 않습니다.
원장 손익과 모델 비용 차감 추정 손익을 구별하며, account별 비용에서는 연결 probe를 제외합니다.
순차 모델 비교는 동일 자료 해시·초기 자금·정책으로 그룹을 나눕니다. 모델의 숨은 사전 지식·비결정성·통계적 우월성은 통제됐다고 주장하지 않습니다.
