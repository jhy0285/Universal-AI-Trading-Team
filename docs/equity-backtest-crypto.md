# 코인(BTC·ETH·SOL) 백테스트

[미국 ETF](equity-backtest.md)·[국내 ETF](equity-backtest-kr.md)와 **같은 기준·같은 절차**를 코인 주요 3종에 적용하는 연구입니다. 주문·지갑·서명·거래소 API 경로가 없고(PAPER ONLY), 장부·DB를 건드리지 않습니다.
이 문서의 "사전 등록" 부분은 **후보를 돌리기 전에** 쓰고 커밋했습니다. 결과를 본 뒤에 바꾸지 않습니다(바꾸면 아래 "변경 기록"에 이유와 함께 남깁니다).

```bash
.venv/bin/python scripts/equity_candidates.py --market crypto   # 받아서 캐시(.state/crypto-cache)하고 절차 실행
```

코드는 `src/trading_team/equity_markets.py`(`CRYPTO` 프로필)와 `equity_backtest.py`(`crypto_candidates`, 엔진은 미국·국내와 공용)입니다. 이 작업으로 엔진에 연환산 기간(`periods_per_year`)과 방어 자산 없음(현금)을 선택 사항으로 추가했고, 기본값은 그대로라 **미국·국내 결과가 바이트 단위로 같음을 확인했습니다**.

## 사전 등록 (후보를 돌리기 전에 고정, 2026-11-11)

| 항목 | 값 |
| --- | --- |
| 벤치마크 | 비트코인(`BTC-USD`) 매수 후 보유 |
| 방어 자산 | **없음.** 시장 밖일 때는 현금이고 수익률 0%입니다. 스테이블코인 이자는 가정하지 않습니다 |
| 유니버스 3개 | `BTC-USD`, `ETH-USD`, `SOL-USD`. 사용자가 지정했습니다 |
| 달력 | 매일(UTC 일봉). 1년 = 365봉, 1달 = 30봉, 변동성·Sharpe 연율화 365. 첫 365봉은 준비 기간이라 평가하지 않습니다 |
| 후보 8개 | 아래 표. 결과를 보기 전에 정했고 조정하지 않습니다 |
| 비용 | 편도 **10bps**(기준), **30bps**(견고성 확인) |
| 개발 구간 | 첫 봉(2014-09-17) ~ 2021-12-31. 후보를 비교하고 하나를 고릅니다 |
| 검증 구간(hold-out) | 2022-01-01 ~ 2026-11-10. 고른 후보에 대해 **한 번만** 엽니다 |
| 데이터 끝 | **2026-11-10**(등록 시점의 마지막 완료 UTC 일). 진행 중인 11-11 봉은 쓰지 않습니다(`data_end`) |
| 통과 기준 | 미국·국내와 같습니다. 개발 구간에서 CAGR이 BTC 보유보다 1%p 넘게 뒤지지 않고, 최대 낙폭이 BTC의 60% 이하이며, CAGR 조건이 30bps에서도 유지 |
| 선택 | 통과 후보 중 개발 구간 Sharpe가 가장 높은 것(동률은 연 주문 수가 적은 것, 그다음 이름). 이것만 씁니다 |
| 판정 | 검증 구간에서도 같은 기준(1%p, 60%)을 만족하면 "통과", 아니면 "미달"로 그대로 적습니다 |

| 후보 | 규칙 |
| --- | --- |
| `trend200` | BTC 종가가 200일 이동평균 위면 BTC 100%, 아니면 현금 |
| `trend100` | 같은 규칙, 100일 이동평균 |
| `mom12_top1` | 월말마다 12-1개월 수익률(365봉 전부터 30봉 전까지)이 양수인 것 중 상위 1개 100%, 없으면 현금 |
| `mom12_top2` | 같은 규칙, 상위 2개 각 50%. 하나만 양수면 나머지 50%는 현금 |
| `mom6_top1` | 6-1개월(182봉 전부터 30봉 전까지), 상위 1개 |
| `mom6_top2` | 6-1개월, 상위 2개 |
| `vol40` | 주의 마지막 봉마다 BTC의 30일 실현 변동성(연율화 365)으로 목표 40%에 맞춘 비중(최대 100%), 나머지 현금 |
| `vol60` | 같은 규칙, 목표 60% |

**매개변수를 고른 방법.** 추세·모멘텀은 ETF 후보와 같은 아이디어를 달력 기준(1년 365봉, 1달 30봉)으로 옮겼습니다. 200일 이동평균은 코인에서 흔히 쓰는 일 단위 기준이며 주식의 200거래일(약 10개월)보다 짧은 약 6.6개월입니다. 변동성 목표 40%·60%는 문헌에서 가져온 고정값이 아닙니다. ETF의 10%·12%를 그대로 쓰면 변동성이 큰 BTC에서는 비중이 아주 작아지므로, 결과를 보기 전에 더 높은 수준으로 정한 값입니다(BTC의 실제 변동성은 측정하지 않고 정했습니다). ETF 목록의 RSI(2) 역추세와 방어 자산 변형은 뺐습니다(방어 자산이 없음).

**결과별 약속.**
- 개발 구간에서 통과 후보가 없으면 검증 구간을 열지 않고 "없음"으로 보고합니다.
- 고른 후보가 검증 구간에서 미달해도 후보를 더하거나 매개변수를 바꿔 다시 돌리지 않습니다. 다시 돌리면 시험 횟수가 늘어난 것이고, 그렇게 적습니다.
- 통과해도 곧바로 실시간 모의 운용에 연결하지 않습니다. 사용자 승인을 받습니다.

## 데이터 점검 (성과를 보기 전에 확인한 것)

전략을 돌리기 전에 받은 데이터만 점검했습니다(Yahoo 차트, 비공식, 2026-11-11 10시경 UTC에 받음).

| 코인 | 봉 | 첫 봉 | 빠진 날 | 중복 | 버린 행 | 원본 SHA-256 앞자리 |
| --- | --- | --- | --- | --- | --- | --- |
| BTC-USD | 4,439 | 2014-09-17 | 0 | 0 | 0 | `66127f45d25b` |
| ETH-USD | 3,290 | 2017-11-09 | 0 | 0 | 0 | `e0fa5dac53a3` |
| SOL-USD | 2,407 | 2020-04-10 | 0 | 0 | 0 | `585d4d3efea7` |

- 받은 시점의 마지막 봉은 2026-11-11(진행 중)이라 위의 `data_end`로 뺍니다.
- 메타데이터의 시간대가 UTC이고 모든 봉이 00:00 UTC에 시작합니다. "시가"는 UTC 자정 가격입니다.
- 배당·분할 이벤트가 없고 수정주가가 종가와 모든 봉에서 같습니다.
- 단발성 급변 점검(그날 BTC는 5% 안에서 움직였는데 해당 코인만 10% 넘게 움직인 날): ETH 31일, SOL 131일(대부분 상장 초기). 코인에서는 실제로 흔한 움직임이라 **데이터를 고치거나 빼지 않습니다.** 결과를 본 뒤에도 이 날들을 이유로 데이터를 바꾸지 않습니다.
- 개발 구간의 유니버스는 실제로는 시기마다 다릅니다. ETH는 2018-11경부터, SOL은 2021-04경부터 12개월 모멘텀 계산에 들어옵니다. 그 전의 모멘텀 후보는 사실상 BTC 하나의 절대 모멘텀입니다.

## 비용과 세금

- 비용은 거래소 수수료 + 스프레드를 합친 **거친 가정**입니다. 거래소·주문 방식·등급에 따라 차이가 커서 10bps를 기준으로, 30bps를 견고성 확인으로 넓게 잡았습니다. 실제 수수료표를 확인한 값이 아닙니다.
- **세금은 모델링하지 않았습니다.** 회전율이 높은 전략은 세금 때문에 실제로 더 불리해질 수 있습니다.

## 한계 (결과를 읽기 전에)

- **유니버스가 사후적으로 골라졌습니다.** 지금 큰 코인 셋을 골랐으므로, 2014~2021년에 이 셋을 골랐을 투자자는 없습니다(특히 SOL). 사라지거나 무너진 코인이 빠진 강한 생존 편향이 있습니다. 결과가 좋아도 이 편향만큼 할인해야 합니다.
- **세 번째 시장입니다.** 미국 11개, 국내 11개에 이어 이번이 8개라 누적 후보가 30개입니다. 어딘가에서 우연히 좋은 결과가 나올 확률이 커집니다.
- **개발 구간이 짧고 강세장 위주입니다.** 평가 기간은 약 6.3년(2015-09~2021)이고 큰 약세장은 2018년 하나입니다.
- **검증 구간의 사전 지식.** 검증 구간(2022~)의 시장 흐름(2022년 급락 등)을 저는 대략 알고 있습니다. 매개변수는 결과를 보기 전에 정했지만 독립 검증은 아닙니다. 가장 깨끗한 검증은 앞으로 쌓이는 실시간 기록뿐입니다.
- 거래소 위험(파산·출금 정지·상장 폐지)은 반영하지 않습니다. 24시간 시장이라 UTC 자정 가격에 체결된다고 가정합니다. 데이터는 Yahoo의 비공식 엔드포인트입니다.

**판정: 통과 후보 없음.** 약속대로 **검증 구간(2022~)은 열지 않았고** 깨끗하게 남아 있습니다.

**읽는 법.**
- 기준이 엄격합니다. BTC의 개발 구간 낙폭이 −83.4%라 허용 낙폭은 그 60%인 −50.0%인데, 가장 얕은 후보도 −61%(`vol40`), −62%(`trend100`)였습니다.
- `trend100`이 가장 가까웠습니다. Sharpe가 가장 높고(1.64) 낙폭이 BTC보다 21%p 얕지만, 연수익 126.2%가 허용선(131.6%)에 못 미쳤습니다.
- 한 코인에 몰아 담는 모멘텀(`mom6_top1`, `mom12_top1`)은 연수익이 BTC보다 높았지만 낙폭이 −90%로 더 깊었습니다. ETH·SOL의 급락을 그대로 맞았습니다.
- 둘로 나누는 모멘텀과 변동성 목표는 낙폭을 줄였지만 수익이 크게 줄었습니다.
- 유니버스의 생존 편향(지금 큰 코인을 고름)은 결과를 좋게 만드는 쪽인데도 통과가 없었습니다.

**확인한 것.** 벤치마크의 연수익 132.6%와 최대 낙폭 −83.4%를 원 가격으로 엔진과 따로 계산해 같은 값을 얻었습니다. 같은 엔진의 미래 정보 누수 검사와 손계산 테스트는 공용 테스트에 있습니다.

**시험 횟수.** 미국 11, 국내 11, 코인 8로 누적 후보 30개입니다. 통과는 미국 1개(검증 구간에서 근소 미달)뿐입니다. 기준을 바꾸거나 후보를 더해 다시 돌리면 시험 횟수가 늘어난 것이고, 사용자 승인과 기록이 필요합니다.
