# 미국 주식·ETF 백테스트

밈코인 전략과는 별개로, **고정 규칙 전략을 과거 일봉으로 시험하는 연구 도구**입니다. 주문을 내지 않고 장부·DB를 건드리지 않습니다. PAPER ONLY 원칙과 전역 모델 하나 원칙은 그대로입니다.
이 도구는 "어떤 전략이 쓸 만한가"를 며칠 기다리지 않고 몇 초 만에 가려내려는 것입니다. 밈코인은 실시간 관측만 가능해 표본이 느리게 쌓입니다.

```bash
.venv/bin/python scripts/backtest_equities.py            # 받아서 캐시하고 보고서 출력
.venv/bin/python scripts/backtest_equities.py --refresh  # 데이터를 다시 받음
.venv/bin/python scripts/backtest_equities.py --cost-bps 10 --json
```

코드는 `src/trading_team/equity_backtest.py`, 테스트는 `tests/test_equity_backtest.py`입니다.

## 방법

| 항목 | 내용 |
| --- | --- |
| 데이터 | Yahoo 차트 엔드포인트의 일봉(2000년부터). **비공식**이라 안정성·약관을 보장하지 않습니다. 앱의 공개 데이터 클라이언트와 같은 식별 User-Agent를 보냅니다(기본 값은 429) |
| 가격 | 배당·분할 반영 수정가격. 시가도 같은 비율로 맞춰 전날 종가→시가→종가가 정확히 이어집니다 |
| 체결 | 신호는 **t일 종가까지의 정보**로 만들고 **t+1일 시가**에 체결합니다. 신호가 자기가 거래하는 가격을 볼 수 없습니다 |
| 비용 | 체결 금액의 편도 `cost_bps`(기본 5bps). 슬리피지·스프레드를 한 숫자로 묶은 가정입니다 |
| 제약 | 레버리지·공매도 불가(가중치 합 ≤ 1). 현금 수익률은 0%(전략에 불리한 보수적 가정) |
| 결측 | 시가·종가가 없거나 양수가 아닌 봉은 버리고 **개수를 표시**합니다. 필요한 시가가 없으면 그날 체결을 하루 미루고 표시합니다. 값을 만들어 채우지 않습니다 |
| 데이터 추적 | 원본 응답을 캐시(`.state/equity-cache`)하고 SHA-256을 출력합니다 |

## 시험한 전략 (매개변수는 문헌 값으로 미리 고정, 조정하지 않음)

| 키 | 규칙 |
| --- | --- |
| `benchmark` | SPY를 사서 보유 |
| `trend` | SPY 종가가 200일 단순이동평균 위면 보유, 아니면 현금 |
| `momentum` | 월말마다 16개 ETF 중 12-1개월 수익률 상위 3개(양수만)를 동일 가중, 없으면 현금 |
| `rsi2` | 200일선 위에서 RSI(2) < 10이면 매수, 종가가 5일선을 넘으면 매도 |

ETF 목록(`DEFAULT_UNIVERSE`)은 SPY, QQQ, IWM, EFA, EEM, TLT, GLD와 업종 SPDR 9개입니다. **사후 선택 위험이 있습니다.** 오늘 아는 대표 ETF라서 이름 자체가 살아남은 종목입니다. 성과로 고르지는 않았지만 이 한계를 결과 해석에 반영하세요. 개별 종목은 생존 편향이 더 커서 넣지 않았습니다.

## 검증

- 단위 테스트 25개: 손으로 계산한 수익·비용 회계, 전환마다 비용 부과, 결측 시 체결 연기·평가 이월, 레버리지·공매도·미지 종목 거부, **미래 가격을 바꿔도 그날 신호가 같음**(모든 전략), 결정론성.
- 독립 대조: 엔진과 다르게 직접 쓴 계산이 SPY 보유와 추세 전략의 최종 자산을 소수점 14자리까지, 주문 횟수(165회)도 같게 재현했습니다.

## 결과 (2026-11-10에 받은 데이터, 2001-01-02 ~ 2026-11-09, 편도 5bps)

| 전략 | 연수익(CAGR) | 변동성 | Sharpe | 최대 낙폭 | 연 주문 수 |
| --- | --- | --- | --- | --- | --- |
| SPY 보유 | **8.9%** | 19.0% | 0.54 | **−55.2%** | 0.0 |
| 추세(SMA200) | 6.9% | 11.2% | 0.65 | −24.4% | 6.4 |
| 모멘텀 상위 3 | **9.5%** | 17.9% | 0.60 | −31.5% | 43.1 |
| RSI(2) | 2.5% | 5.9% | 0.44 | −15.0% | 15.0 |

| 구간 | SPY 보유 | 추세 | 모멘텀 | RSI(2) |
| --- | --- | --- | --- | --- |
| 2001–2012 | 2.5% | 2.7% | **7.7%** | 1.9% |
| 2013–2026 | **14.7%** | 10.6% | 11.1% | 3.0% |

비용 민감도(전체 구간 CAGR): 모멘텀은 0bps 9.8%, 5bps 9.5%, 10bps 9.1%, 25bps 8.1%로 25bps에서 SPY 보유(8.9%)보다 낮아집니다. 3년 롤링 구간에서 SPY 보유를 이긴 비율은 추세 21%, 모멘텀 44%, RSI(2) 16%입니다.

**읽는 법(과장하지 말 것).**
- **SPY 보유를 일관되게 이긴 전략은 없습니다.** 모멘텀만 전체 구간에서 근소하게 높지만(9.5% 대 8.9%), 우위는 SPY가 부진했던 2001–2012에 몰려 있고 2013년 이후에는 뒤집니다(11.1% 대 14.7%). 비용이 25bps로 오르면 우위가 사라집니다.
- **줄어드는 것은 수익이 아니라 낙폭입니다.** 모멘텀·추세는 최대 낙폭이 −55%에서 −31%·−24%로 줄고 Sharpe가 조금 높습니다. 현금 수익률 0% 가정은 현금이 많은 전략에 불리해서 이 Sharpe 차이를 줄여 보이게 합니다.
- 전략 3개를 비용 4수준으로 본 것이며 매개변수는 조정하지 않았습니다. 겹치는 창은 독립이 아니고, 세금·환율·미래 체제 변화는 반영하지 않았습니다. **이 결과는 앞으로의 수익을 약속하지 않습니다.**
- 2013을 가르는 두 구간은 매개변수 맞춤이 아니라 체제 의존성을 보려는 것입니다.

## 하지 않은 것

- **LLM 판단의 백테스트.** 모델은 과거 가격과 사건을 학습해 알고 있어서 과거 구간에 쓰면 미래 정보가 새어 들어갑니다. LLM 역할은 앞으로의 모의 운용(실시간 이전 값만 있는)에서만 평가할 수 있습니다.
- 개별 종목, 일중 체결 시뮬레이션, 세금·환율, 한국 주식.
- 모의 운용 연결. 일봉이므로 하루 한 번만 판단하면 되고, 5분 쉬면 꺼지는 클라우드 환경에서도 가능합니다. 개선 제안은 [학습 루프](learning-loop.md)의 반자동 방식(제안 → 검증 → 사용자 승인)을 따릅니다.
