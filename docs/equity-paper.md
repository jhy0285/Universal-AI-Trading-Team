# 미국 ETF 실시간 모의 운용

[백테스트](equity-backtest.md)에서 고른 전략 `mom12_top5_def`와 벤치마크 `spy_buy_hold`(SPY 보유)를 **실시간으로** 시험합니다. 검증 구간(2020~)은 이미 한 번 열렸으므로(근소하게 기준 미달), 앞으로 쌓이는 이 기록이 유일하게 깨끗한 검증입니다.
PAPER ONLY입니다. 주문·지갑·서명 경로가 없고, 밈코인 거래 장부와 LLM을 쓰지 않으며, 새 테이블 3개(`equity_paper_runs`, `equity_paper_decisions`, `equity_paper_nav`)만 추가합니다.

## 하루에 하는 일

`trading-team equity-paper run` 한 번이 아래를 모두 합니다. 같은 데이터로 다시 실행해도 아무것도 바뀌지 않고(멱등), 며칠 놓쳤으면 따라잡습니다.

1. ETF 16종과 SHY의 일봉을 받습니다(Yahoo 차트, 비공식). 원본 응답의 SHA-256을 모아 하나의 **데이터 해시**로 남깁니다.
2. **확정된 마지막 장까지만** 씁니다(뉴욕 16:30 이후). 장중의 미완성 봉으로 결정하지 않습니다.
3. 고정 규칙이 그 데이터로 내리는 **목표 비중을 결정으로 기록**합니다(`equity_paper_decisions`). 시각(`recorded_at`)과 데이터 해시를 함께 적고, 한 번 쓰면 바꾸지 않습니다. 다음 장이 열리기 전에 기록했으면 `timely = true`입니다.
4. 기록된 결정을 백테스트와 **같은 엔진**으로 재생해 모의 자산을 계산합니다(결정은 종가, 체결은 다음 날 시가, 편도 5bps). 새로 생긴 날만 `equity_paper_nav`에 **덧붙입니다**.

시작일에는 모멘텀 규칙이 월말이 아니어도 그 시점의 목표 포트폴리오로 시작합니다(`target`). 이후에는 규칙대로 월말에만 바꿉니다.

## 믿을 수 있게 하는 장치

| 장치 | 내용 |
| --- | --- |
| 결정 불변 | `(strategy, data_through)`가 유일합니다. 재실행·재계산이 기록된 결정을 덮어쓰지 않습니다 |
| 제때 여부 | 다음 영업일 09:30 뉴욕 이전에 기록했는지를 `timely`로 남깁니다. 놓쳐서 따라잡은 결정은 `false`이며 `late_decisions`로 보입니다 |
| 데이터 추적 | 결정과 자산 행마다 그날 쓴 데이터의 해시를 적습니다 |
| 자산 불변 | 이미 적은 날의 자산은 다시 쓰지 않습니다. 공급자가 과거 가격을 고치면 `revised_days`로 세기만 합니다 |
| 백테스트와 동일 | 모의 자산은 백테스트 엔진의 재생 결과라 둘이 갈라질 수 없습니다. 테스트가 손계산·엔진과의 일치를 확인합니다 |

## 판정 규칙 (전략과 함께 2026-11-10에 고정)

기준은 백테스트와 같습니다: 연수익이 SPY 보유보다 1%p 넘게 뒤지지 않고, 최대 낙폭이 SPY의 60% 이하.
단 **모의 거래일이 252일 이상일 때만** 판정하고, **낙폭 조건은 SPY 자신의 낙폭이 15% 이상일 때만** 판정합니다(그렇지 않으면 `drawdown_not_testable`). 폭락이 없으면 낙폭 비교가 의미가 없습니다. 그 전에는 `insufficient_sample`입니다.
기준을 중간에 바꾸지 마세요. 바꾸려면 결과를 본 뒤의 변경이라고 기록하고 사용자 승인을 받습니다.

## 실행

```bash
DATABASE_URL=sqlite:///.state/equity-paper.sqlite3 .venv/bin/trading-team equity-paper run      # 하루 한 번
DATABASE_URL=sqlite:///.state/equity-paper.sqlite3 .venv/bin/trading-team equity-paper status   # JSON
```

- `equity-paper`는 LLM 설정 없이 돌고, 메인 장부 계정을 만들지 않으며 새 테이블만 만듭니다.
- 워커로 돌리려면 `EQUITY_PAPER_ENABLED=true`(기본 꺼짐)를 켭니다. 서울 07:30(미국 장 마감 후, 다음 개장 전)에 실행하고 시작할 때 한 번 따라잡습니다. 비용은 `EQUITY_PAPER_COST_BPS`(기본 5), 시작 자금은 `EQUITY_PAPER_INITIAL_CASH`(기본 10,000 USD)이며 **처음 시작할 때만** 적용됩니다.
- 상태는 `GET /equity-paper`로도 읽습니다(읽기 전용).
- 두 곳에서 동시에 실행하지 마세요. 유일 제약이 중복을 막지만 실행 하나는 실패합니다.

## 시작 상태 (2026-11-10)

시작 데이터는 2026-11-09 종가입니다. 모멘텀 전략의 시작 목표는 EEM·QQQ·XLE·XLK·XLV 각 20%(양수 모멘텀 5개가 모두 채워져 SHY는 없음), 벤치마크는 SPY 100%입니다. 첫 모의 거래일은 2026-11-10입니다.

## 한계

- **저장 위치.** 기록은 실행한 곳의 DB에 있습니다. 클라우드 세션의 디스크에 두면 컨테이너가 회수될 때 사라지고, 그러면 사전에 기록한 결정이라는 증거도 함께 잃습니다. 몇 달을 가야 하는 시험이므로 **장기 운용은 사용자 PC나 서버에서, PostgreSQL이나 지속 디스크로** 하세요(`compose.yaml` 참고).
- 자산은 부동소수 계산을 소수 6자리로 반올림한 **모의 지수**입니다. 주문 단위 장부가 아니며 분수 주식과 일정한 비용률(5bps)을 가정합니다. 세금·환율·실제 시가 체결 가능성은 반영하지 않습니다.
- 데이터는 Yahoo의 비공식 엔드포인트입니다. 약관·안정성을 보장하지 않으며 조용히 형식이 바뀔 수 있습니다(바뀌면 결정을 기록하지 않고 실패합니다).
- 월말 판정은 마지막 봉에서는 "다음 평일이 다른 달이면 월말"로 합니다. 다음 평일이 휴장이면 결정이 하루 빨리 올 수 있습니다.
- 시료가 얇습니다. 폭락이 와야 낙폭 기준이 평가되므로 판정까지 수개월~수년이 걸릴 수 있습니다.

## 하지 않은 것

- LLM 판단의 평가. 실시간 기록이 쌓이면 LLM 역할을 같은 방식으로 앞으로의 데이터에서만 시험할 수 있습니다.
- 대시보드 화면, 알림.
- 여러 전략 후보의 그림자 운용. 후보를 늘리면 시행 횟수가 늘어 판정이 약해집니다.
