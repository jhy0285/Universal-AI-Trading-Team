# 국내 ETF 백테스트

[미국 ETF 백테스트](equity-backtest.md)와 **같은 규칙·같은 기준·같은 절차**를 국내 상장 ETF에 적용하는 연구입니다. 주문·지갑·서명 경로가 없고(PAPER ONLY), 장부·DB를 건드리지 않습니다.
이 문서의 "사전 등록" 부분은 **후보를 돌리기 전에** 쓰고 커밋했습니다. 결과를 본 뒤에 바꾸지 않습니다(바꾸면 아래 "변경 기록"에 이유와 함께 남깁니다).

```bash
.venv/bin/python scripts/equity_candidates.py --market kr    # 받아서 캐시(.state/kr-cache)하고 절차 실행
.venv/bin/python scripts/equity_candidates.py --market us    # 미국(기존 결과와 동일해야 함)
```

코드는 `src/trading_team/equity_markets.py`(시장별 고정 설정)와 `equity_backtest.py`(엔진, 미국과 공용)입니다.

## 사전 등록 (후보를 돌리기 전에 고정)

| 항목 | 값 |
| --- | --- |
| 벤치마크 | KODEX 200(`069500.KS`) 매수 후 보유. 미국의 SPY에 해당 |
| 방어 자산 | KODEX 국고채3년(`114100.KS`). 미국의 SHY에 해당(만기 1~3년 국채 ↔ 3년 국채). 현금은 수익률 0% |
| 유니버스 20개 | KODEX 200, 코스닥150, 업종 11개(반도체·은행·자동차·에너지화학·철강·건설·보험·운송·헬스케어·IT소프트웨어·IT하드웨어), 해외 5개(미국 나스닥100·S&P500(H)·유로스톡스50(H)·중국 A300·니케이225(H)), 국고채10년, 금 선물. 정확한 티커는 `equity_markets.py`의 `KR_UNIVERSE` |
| 후보 11개 | 미국과 같은 규칙, 같은 매개변수(문헌 값). `trend`·`momentum`·`rsi2`·`trend200_def`·`trend100_def`·`mom12_top3_def`·`mom12_top5_def`·`mom6_top3_def`·`mom6_top5_def`·`vol10_def`·`vol12_def`. 단일 자산 규칙은 KODEX 200에, 모멘텀은 위 유니버스에 적용합니다. 조정하지 않습니다 |
| 비용 | 편도 **10bps**(기준), **20bps**(견고성 확인) |
| 개발 구간 | 첫 거래일 ~ 2019-12-31. 후보를 비교하고 하나를 고릅니다 |
| 검증 구간(hold-out) | 2020-01-01 ~ 데이터 끝. 고른 후보에 대해 **한 번만** 엽니다 |
| 통과 기준 | 개발 구간에서 CAGR이 벤치마크보다 1%p 넘게 뒤지지 않고, 최대 낙폭이 벤치마크의 60% 이하이며, CAGR 조건이 20bps에서도 유지 |
| 선택 | 통과 후보 중 개발 구간 Sharpe가 가장 높은 것(동률은 연 주문 수가 적은 것, 그다음 이름). 이것만 씁니다 |
| 데이터 시작 | 2009-04-17. 아래 "데이터 점검" 참고 |
| 판정 | 검증 구간에서도 같은 기준(1%p, 60%)을 만족하면 "통과", 아니면 "미달"로 그대로 적습니다 |

**결과별 약속.**
- 개발 구간에서 통과 후보가 없으면 검증 구간을 열지 않고 "없음"으로 보고합니다.
- 고른 후보가 검증 구간에서 미달해도 후보를 더하거나 매개변수를 바꿔 다시 돌리지 않습니다. 다시 돌리면 시험 횟수가 늘어난 것이고, 그렇게 적습니다.
- 통과해도 곧바로 실시간 모의 운용에 연결하지 않습니다. 사용자 승인을 받습니다.

**유니버스를 고른 방법.** 자산군(국내 지수, 업종, 해외 지수, 채권, 금)마다 대표 ETF 하나를 2018년 이전 상장 기준으로 골랐습니다. 성과를 보고 고르지 않았고, 성과를 계산하기 전에 데이터 가용성만 점검했습니다. 제외한 것: TIGER 200(KODEX 200과 거의 같음), KODEX 단기채권(`153130.KS`, 방어 자산의 다른 후보). 상장이 늦은 ETF(예: 코스닥150은 2015-10)는 12개월 이력이 쌓인 뒤부터 순위에 들어갑니다.

## 데이터 점검 (성과를 보기 전에 확인한 것)

- **Yahoo의 빈 자리 행.** KODEX 200 등은 2007-02-08부터 2009-04-16까지 값이 없는 행만 돌려줍니다(578일). 앞에 2007-01-29~02-07의 8개 봉만 있어서 그대로 쓰면 2년 공백을 가로질러 12개월 모멘텀·이동평균을 계산하게 됩니다. 그래서 **2009-04-17 이전 봉은 쓰지 않습니다**(`history_start`). 값을 만들어 채우지 않았고, 이 날짜는 가격이 아니라 빈 행이 끝나는 날에서 정했습니다.
- **공급자 공백.** 2015~2024년에 모든 ETF가 같은 날 값이 비는 날이 29일 있습니다(2023년 7~8월에 집중). 엔진이 이런 날을 버리고 개수를 출력합니다. 그날 사이의 수익은 하루가 아니라 며칠에 걸친 한 번의 변화로 계산됩니다.
- **배당 반영.** 수정주가(adjclose)에 분배금이 반영되어 있는지 확인했습니다. KODEX 200과 채권 ETF는 분배금 이벤트가 수십 건 있고 수정주가 비율이 시작 0.66~0.75에서 1.0으로 이어집니다. 금·선물형 ETF는 분배금이 거의 없는 상품입니다. 다만 공급자가 조용히 틀릴 수 있다는 위험은 남습니다.
- **시각.** 국내 일봉의 타임스탬프는 09:00 KST(=00:00 UTC)라 UTC 날짜가 한국 날짜와 같습니다.

## 비용과 세금

- 국내 상장 ETF는 매도 시 **증권거래세가 면제**됩니다([KB자산운용 안내](https://kbam.co.kr/insights/guide/etf-tax-guide-domestic-vs-other-types), [KB증권 ETF 세금](https://www.kbthink.com/main/guide/etf-tax.html)). 그래서 비용은 위탁수수료 + 반호가 스프레드이며, 업종 ETF가 얇은 점을 감안해 10bps로 둔 **거친 가정**입니다. 이 자료들은 세무사·증권사 안내이며 공식 법령으로 다시 확인하지 않았습니다.
- **세금은 모델링하지 않았습니다.** 국내주식형 ETF의 매매차익은 비과세이지만, 해외주식형·채권·금 ETF의 매매차익과 모든 분배금은 배당소득세(15.4%)가 붙습니다. 회전율이 높은 전략이 이 때문에 실제로는 더 불리해질 수 있습니다.

## 한계 (결과를 읽기 전에)

- **개발 구간이 짧습니다**(약 9.7년, 2010~2019). 미국(19년)의 절반입니다. 통과가 우연일 가능성이 더 큽니다.
- **두 번째 시장입니다.** 같은 후보 11개를 미국에서 한 번 돌렸고 이번이 두 번째라서, 어딘가에서는 우연히 좋은 결과가 나올 확률이 커집니다. 미국에서 본 결과가 이 설계에 영향을 줬을 수 있습니다(같은 규칙을 그대로 쓴 것).
- **생존 편향.** 오늘 존재하는 ETF만 목록에 있습니다. 중간에 폐지된 ETF는 빠져 있습니다.
- **국내 편중.** 유니버스 20개 중 13개가 국내 주식이라 모멘텀 상위 5개가 서로 비슷하게 움직일 수 있습니다.
- **검증 구간의 사전 지식.** 검증 구간(2020~)의 시장 흐름을 저는 대략 알고 있습니다. 규칙과 매개변수는 미국 절차에서 가져와 바꾸지 않았지만, 이 점은 독립 검증이 아닙니다. 가장 깨끗한 검증은 앞으로 쌓이는 실시간 기록뿐입니다.
- 연율화에 252일을 그대로 씁니다(국내 거래일은 연 약 245일). 변동성·Sharpe가 조금 어긋나지만 모든 후보에 똑같이 적용됩니다.
- 환율은 해외 지수 ETF가 원화로 상장되어 있어 가격에 이미 포함되며, 환헤지(H) 상품은 헤지 비용·괴리를 따로 보지 않았습니다. 세금·슬리피지 실측은 없습니다.
